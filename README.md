## Project overview

Testing a lithium-ion cell until it fails can take months. This project asks whether the **total cycle life** of a cell can be predicted using only measurements from its **first 100 charge–discharge cycles**, so that long life tests could be shortened.

- **Data:** 169 commercial LFP/graphite 18650 cells (MATR dataset, 81 fast-charging protocols, 30 °C)
- **Inputs:** 8 features computed from cycles 1–100 (discharge capacity at cycles 10 and 100, capacity change and slope, mean/max temperature, mean internal resistance, and the log-variance of ΔQ₁₀₀₋₁₀(V) from Severson et al.)
- **Target:** cycle life, modelled as log₁₀(cycle life)
- **Models:** Dummy (mean) baseline, Linear Regression, Random Forest, Elastic Net
- **Validation:** 80/20 train/test split (random_state = 42), 5-fold cross-validation and GridSearchCV on the training set only; the test set is used once for the final model

### Main result

The final model is **Elastic Net without the resistance feature** (resistance readings were missing or invalid for many cells, so dropping it keeps all 135 training cells).

| Model (test set, 34 cells) | MAE (cycles) | RMSE (cycles) | MAPE (%) |
|---|---|---|---|
| Elastic Net (without resistance) | 99.2 | 151.6 | 19.6 |
| Dummy (mean) baseline | 300.2 | 417.9 | 44.1 |

All code is in one notebook, organized in sections:

| Section | Content |

## How to run

**In Google Colab**

1. Put `MATR.zip` and `Life labels.zip` in the Google Drive folder `MyDrive/CHE1147/` (easiest: open the shared Drive link above and add a shortcut of the `CHE1147` folder to My Drive; see `data/README.md`).
2. Open `notebooks/battery_cycle_life_prediction.ipynb` in Colab (File → Upload notebook, or File → Open notebook → GitHub).
3. Keep `USE_COLAB = True` in Section 1.2.
4. Click **Runtime → Run all**. The first run unzips the data, which takes a few minutes. Allow access to Google Drive when asked.

**Locally**

1. Unzip both files into `data/` as described in `data/README.md`.
2. Start Jupyter from the repository folder:
   ```bash
   jupyter notebook notebooks/battery_cycle_life_prediction.ipynb
   ```
3. Set `USE_COLAB = False` in Section 1.2.
4. Run all cells from top to bottom (**Kernel → Restart & Run All**).

Training, hyperparameter tuning and evaluation all run inside the notebook; no separate scripts are needed. Results are reproducible because the train/test split and cross-validation folds use fixed random seeds.
